# Decisions and lessons

Important choices, and attempts that were tried and dropped. Each line has its reason and where it comes from. Read this before changing one of these areas. Remove a line when it no longer holds; do not keep history here.

## Decisions

| Decision | Why | Source |
| --- | --- | --- |
| Code themes installed on the editor of `<strudel-editor>` with its own classes, reached from the live view (code-themes D1) | `@strudel/repl` bundles its own CodeMirror and themes: a theme registered from the app never reaches the panel. The tags come from `strudelTheme`'s style, the `Decoration` class from a decoration in place (a flash), `appendConfig` from a compartment's effect. Pinned to Strudel 1.3.0: `check-code-themes.cjs` fails when an upgrade moves them. | [openspec/changes/code-themes](../../openspec/changes/code-themes/design.md) |
