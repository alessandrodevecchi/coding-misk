# Decisions and lessons

Important choices, and attempts that were tried and dropped. Each line has its reason and where it comes from. Read this before changing one of these areas. Remove a line when it no longer holds; do not keep history here.

## Decisions

| Decision | Why | Source |
| --- | --- | --- |
| Strudel, from npm, never forked | It runs in the browser with no install. A fork only if the audio engine itself must change. | DEVLOG 2026-10-03, [CONTEXT](../CONTEXT.md#key-decisions) |
| Tempo is set by the player at bar lines, never inside a pattern | `.cps()` in a pattern recomputes queued events with a stale reference and drops notes. | [MUSIC-ENGINE](../MUSIC-ENGINE.md#strudel-gotchas-learned-the-hard-way) |
| Strudel's master stays at 0.6 | All layers together go above 1 and clip. | [CONTEXT](../CONTEXT.md#key-decisions) |
| Guitar level after the distortion (`postgain`) | Before heavy drive, `gain` only changes the saturation. | [CONTEXT](../CONTEXT.md#key-decisions) |
| The output peak is the level limit, a track line is a warning | A line passes the master before the output, and browser audio is floating point: only the output and files clip. Loud styles may set `headroom` (up to 1.5) for single lines (level-headroom). | [sound-and-levels](sound-and-levels.md) |
| A look-ahead limiter worklet on the master, ceiling 0.95, in the app and every export | 11 of 26 songs clipped in exports with every line below 1.0. The worklet keeps every sample at the ceiling at most and leaves the sound bit for bit below it (measured: 1.2e-7 difference, from the guard's curve). Rejected: `DynamicsCompressorNode`, it adds a makeup gain (+0.86 dB below the threshold, so not transparent) and overshoots on transients (1.07 on a click). The style's `headroom` sets the push into it. | [sound-and-levels](sound-and-levels.md), DEVLOG 2026-10-19 |
| Built-in songs are song files, not hand code | Every song must open and be edited in Compose. | [CONTEXT](../CONTEXT.md#key-decisions) |
| Parts are stored as ideas, written in their shortest exact form | Short code like a live coder's, growth from an idea, variation instead of replacement. 1,071,662 events compared: no difference. | [DEVLOG](../../DEVLOG.md#2026-10-18-parti-come-idee-idea-model-70), [VARIETY](../VARIETY.md#one-root) |
| Randomness is always seeded | The same song sounds the same in the app, exports and checks. | [VARIETY](../VARIETY.md#one-root) |
| The generator picks rules, never free notes | Parts stay in key and on chord tones; melodies are not random. | [ENDLESS](../ENDLESS.md#material) |
| No app function takes a Strudel name or synonym | `o`, `drive` and `voice` hid Strudel's own (`o` is `orbit`, `drive` a filter overdrive). They became `chan`, `crunch` and song functions. `env` is Strudel's, so the envelope is `plk`. `grit` is a track setting, so distortion is `crunch`. | [DEVLOG](../../DEVLOG.md#2026-10-19-funzioni-del-brano-song-functions-73) |
| Classic and Crescendo keep their sound and steps | New growth only in the Live coder profile; fixtures guard the old ones. `CRESCENDO_VERSION` 2 keeps the random seed name `crescendo-1`. | [VARIETY](../VARIETY.md), [DEVLOG](../../DEVLOG.md#2026-10-18-parti-come-idee-idea-model-70) |
| The Live coder keeps the id `switch` | Songs, recipes and storage name it; only the label changed. | [profiles.md](profiles.md) |
| Typing never rushes | A step waits for its typing, or a new line is pasted whole after a pause. Typing faster than a person looked fake. | [DEVLOG](../../DEVLOG.md#2026-10-19-forme-di-crescita-growth-shapes-64) |
| The radio's Profile option overrides artist and style profiles; it never filters artists | Filtering would leave little to play (one built-in artist, Cursor Bloom, has Live coder weights) or change the music to satisfy it. The profile is how a song builds, not its taste. | [radio-profiles design](../../openspec/changes/radio-profiles/design.md) D3 |
| Recipes saved without the Profile option replay as Classic | They were heard in blocks; no warning needed. | radio-profiles D11 |
| The Compose controls never reach the radio; a window of Classic songs, all shown, plays with fixed Classic controls as before | The window song names no profile: a Crescendo pick in Compose with the Live build switch on grew the radio window. Classic sessions keep their exact code. | radio-profiles 1.1, 4.1, DEVLOG 2026-10-19 |
| Recipes record a growth marker (`growth: 1`); a recipe without it replays every song in blocks | Sessions recorded before songs grew on air (stages 1 to 3 recorded the Profile option already) must replay as they were heard. | radio-profiles stage 4, DEVLOG 2026-10-19 |
| The incoming song is hidden when it grows, shown when it is Classic, by default | A growing song comes in like a DJ's next record: it plays from its full code and appears whole when it goes on air; the option shows it in the panel. | radio-profiles D7, owner decision 5 |
| Songs not on air play in full form on orbits moved up by 20, their constants renamed, their `S$:` local | Two songs in one evaluated code must not share buses, constant names or a solo. The events equal the full form of the window at every step of a transition (check-compact-code). | radio-profiles 4.2, 4.3 |
| Radio songs grow in a Web Worker | A growth takes up to 3 s; in the page it would stop the scheduler and the music. The worker gets the page's voice context and language, so a song grows there as in the page. | radio-profiles stage 4, DEVLOG 2026-10-19 |
| A command on a grown radio song is the next waypoint of its growth: the steps before its boundary stay, small typed moves lead to the director's rewrite, its written form plays from the arrival (a phrase boundary) | Growing the steered song again (stage 4) changed steps already heard and typed. The moves come from the difference between the code on air and the rewrite, so every command works without a rule of its own. | radio-profiles D9, stage 5 |
| The boundary of a command on a grown song waits for its typing (the next phrase or the one after); each move gets the bars its typing needs, and the arrival moves a phrase later when its edit needs more time | Typing never rushes (owner). Near the end of the song the moves are fewer and larger and the paste rule applies. | radio-profiles D9, stage 5 |
| Growth marker 2 for sessions whose grown songs steer by waypoints; marker 1 replays as stage 4 | Recipes saved in stage 4 replay as they were heard. | radio-profiles stage 5 |
| Song 0 from Compose keeps its profile and the Compose controls; its growth is recorded as profile and controls in the recipe's `lead` and grown again on replay, while the director follows the song as written | The handover changes nothing on screen, and the songs after it stay those of a Classic lead. Storing the grown build would make recipes large. | radio-profiles D2, stage 6 |
| Save and Open in Compose on a grown radio song give the song as written (the director's song as steered, or song 0 as written) with the profile it played with, not the grown build | Compose grows it again with its own controls; a saved song stays a written song (D1, owner decision 1). | radio-profiles D1, stages 4 and 6 |
| A steered grown song keeps the song before its commands as its code reference (`codeRef`) | Song functions and written levels come from the whole song; a rewrite of its future renamed the functions of the code already on screen. | radio-profiles stage 5 |
| The chooser on air puts the listener's moves first, then the moves toward the coming energy or density target | A curve point is reached sooner than with the default chooser (check:radio-profiles 5.5). A later decision model takes the same arguments. | radio-profiles D10 |
| Radio growths are fitted, with one phrase of slack | A growth that replaces exactly its bars rushed the typing more (3.78 rushed steps a song over 50 songs) than Compose's Live coder songs (3.23); one phrase more and 8 tried boundaries give 3.16 and every song within a phrase of its plan. | radio-profiles 3.4, 3.5, DEVLOG 2026-10-19 |
| The built-in Live coder artist (Cursor Bloom) weighs the Live coder 5 to 1 over Crescendo, never Classic, and keeps `explore` 0.05 | A Live coder session with a character; Crescendo now and then and a rare song outside the four live coder styles keep variety, and the Profile control forces pure Live coder. Invented name and bio, no real people. | radio-profiles D14, task 8.1 |
| Sections (`fnLanes`) is a technical function in the compact preset, not a code view | The owner wants compact code for every song, Classic included; full keeps Classic and Crescendo byte for byte. With it the code of every view is the code of the moment edited in place, a step at each section and clip change. The growth keeps measuring its typing on the Live coder code without Sections, so no grown build and no `SHAPES_VERSION` (which seeds the shape draw of every song) had to change. | code-lanes, DEVLOG 2026-10-24 |
| Display options apply on air; the growth measures typing with the track names | Comments, functions and typing change only the code shown, so the radio applies them to the song on air at its next edit and never records them (a replay uses those set when it starts). The Live coder's shape choice and the steering of a non-Custom song measured the typing on the profile's own code; when the Live coder's default dropped the track names (title only) that moved 5 Live coder fixtures and a radio fixture, so the measure keeps the track names (`tracks: true`): the growth and the fixtures stay as they were, no `SHAPES_VERSION` bump, and the longer code never rushes the shorter one. | radio-profiles 9.1, 9.2 |
| Section lanes of the Live coder play from the hidden mixer | Lines were duplicated per section with `.mask(sectionN)`; now one line is edited in place. | [DEVLOG](../../DEVLOG.md#2026-10-19-live-coder-righe-modificate-sul-posto-niente-incolla-forzato-con-durata-libera-durata) |
| Complexity 0 and the source `patterns` give the old songs | Saved sessions and fixtures must not move. | [DEVLOG](../../DEVLOG.md#2026-10-19-generatore-di-materiale-material-generator-71) |
| Vary always composes, Swap never composes | Two clear buttons: new notes, or another ready part. | [DEVLOG](../../DEVLOG.md#2026-10-19-varia-e-scambia-nella-console-materiale-accanto-alle-manopole-radio-variation-3-41-62-7-24) |
| Raise `DIRECTOR_VERSION` or `SHAPES_VERSION` when fixtures move on purpose | Saved sessions warn that they may sound different; shapes draw anew. | `AGENTS.md` |
| At most 4 to 5 layers, dark or tense melodies, fades over cuts | The owner's taste after listening. | [CONTEXT](../CONTEXT.md#owner-preferences-and-feedback-keep-applying-these) |
| Material rules written from general techniques | No passage of a course is reused, so no credit line is needed. | [ENDLESS](../ENDLESS.md#material) |
| A fast export uses a fresh render page each time | Strudel's audio layer keeps one context and pools nodes. | [ARCHITECTURE](../ARCHITECTURE.md#fast-export-8) |
| A song's configuration is part of the song; Compose changes are trials per song (song-own-settings) | A global Compose choice made kellerlicht open as Crescendo for 7:58 while its card said 4:50, and leaked to every song. The old global keys are left unread, not migrated: no saved song changes how it plays, and the per-song switches of that time were never stored. | [song-own-settings](../../openspec/changes/song-own-settings/proposal.md) |
| ↺ Original song and ↺ Original configuration side by side in the song actions | ↺ Original song (former Restore original) brings back a built-in song whole and clears its trial; ↺ Original configuration only undoes the trial. Both outside the Live build panel: the original configuration may be the Live build off, with the panel hidden. Disabled with their tooltip when there is nothing to restore. | [song-own-settings](../../openspec/changes/song-own-settings/specs/live-build/song-own-settings/spec.md) |

## Rejected attempts

| Attempt | Why it was dropped | Source |
| --- | --- | --- |
| Growing a steered radio song again from the steered song (stage 4) | The steps already heard and typed changed with every command. Replaced by waypoints (stage 5). | radio-profiles D9 |
| Hosting the app as a web artifact | Its sandbox blocks Strudel's audio worklets loaded from `data:` URLs: no sound. | DEVLOG 2026-10-04 |
| App helpers named after Strudel functions (`o`, `drive`, `voice`) | They shadowed Strudel's functions in the app and in code opened in Strudel. | [DEVLOG](../../DEVLOG.md#2026-10-19-funzioni-del-brano-song-functions-73) |
| Typing faster to keep up with a step | It looked like a machine. Paste the line, or let the step wait. | [DEVLOG](../../DEVLOG.md#2026-10-19-forme-di-crescita-growth-shapes-64) |
| Forced paste with free duration | A pasted line at the start of a build broke the illusion. With free duration the step waits. | [DEVLOG](../../DEVLOG.md#2026-10-19-live-coder-righe-modificate-sul-posto-niente-incolla-forzato-con-durata-libera-durata) |
| Typing mistakes with a chance per character | Most edits change 1 to 7 characters, so a mistake almost never happened. A short edit now counts as 20 characters. | [DEVLOG](../../DEVLOG.md#2026-10-18-errori-di-battitura-visibili-typing-mistakes-64) |
| `*n` around an alternation in the idea writer | Under `*n` the alternation counts its cycles faster and the notes change. | [DEVLOG](../../DEVLOG.md#2026-10-18-parti-come-idee-idea-model-70) |
| `!` whenever it repeats | `[~ x!3]` is harder to read than `[~ x x x]`. Use `!` only when it saves 3 characters or more. | [DEVLOG](../../DEVLOG.md#2026-10-18-parti-come-idee-idea-model-70) |
| `Fmaj7` and `n("0 2").add("4")` in ideas | `voicing()` knows `F^7`, not `Fmaj7`. An `add` outside the string does nothing on `n`: degrees come first, notes after. | [DEVLOG](../../DEVLOG.md#2026-10-18-parti-come-idee-idea-model-70) |
| Converting between Strudel code and tracker modules | They do not map well. Import as code, export to the module format and a second audio engine were dropped. | DEVLOG 2026-10-05 |
| Patterns shared across tracks at song level | Not now: per-track patterns are enough. Shared progressions (`shared`) cover the common case. | [CONTEXT](../CONTEXT.md#ideas-to-re-evaluate-lowest-priority) |
| The words "composition" and "scene" in the interface | Too close to the Compose tab; sections replaced scenes. | [CONTEXT](../CONTEXT.md#vocabulary-decided-2026-10-06) |
| A sound with `stretch` in the first tenth of a second of a render | It stayed silent. Fast export now starts 0.1 s later. | [DEVLOG](../../DEVLOG.md#2026-10-19-voce-strumento-voice-instrument-39) |
