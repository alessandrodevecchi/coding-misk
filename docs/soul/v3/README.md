# Song soul, v3

The third generation of the song soul views (`#46`), after the owner's notes on v2 (`../v2`); the reference for the app. Changes from v2:

- **B Terrain:** rows disappear and are traced again, the scan line turns dashed and running or carries a glowing point, stray pixels and clusters light up under the terrain, a patch turns to big pixels, rare slices of the screen slide sideways.
- **C Sphere:** spikes and craters sit on the mesh, so the sphere's own lines draw them; spikes vary in size and tip (dot, square, triangle, ring, cross); craters are deeper and marked by rings; each song adds its own lobes to the globe.
- **G Particles:** a few dots twinkle.
- **I Aura:** each element moves its own way: energy breathes on the beat, density turns, brightness fades in and out, tension drifts, voice breathes slowly.
- **Messages:** more "analyzing" lines (science fiction, space opera, horror) and a list of "recalibrating" lines for the interference effect.

Same parameters as v1 (`?v=a` to `j`, `&song=2`, `&hw=1`, `&play=1&per=6&songs=1`).
